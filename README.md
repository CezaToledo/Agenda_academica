SCRIPT DE PREENCHIMENTO DA AGENDA GOOGLE

Esse script tem os seguintes objetivos:
- Conseguir todas as reservas disponíveis no sistema de reserva;
- Filtrar as reservas por somente as ativas e futuras;
- Inserir as reservas filtradas numa agenda pública do google.

*ANTES* de rodar:
- Insira as informações das credenciais:
   - Token;
   - Id do cliente;
   - Id do projeto no google cloud.

Para rodar:
- Abra o cmd;
- Rode 'python bubble.py' no repositório.
